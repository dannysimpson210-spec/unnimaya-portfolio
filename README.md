# Unnimaya Manoj – Portfolio Website

A bold, dark + colorful portfolio site designed for job applications and personal branding.

## How to view

1. Open `index.html` in any modern browser (Chrome, Firefox, Edge, Safari).
2. Or drag the file into your browser window.

## How to customize

### 1. Personal details
- Replace the email `hello@unnimaya.com` with her real email.
- Update the Instagram link if the handle is different.
- Edit the About section text with her real bio.

### 2. Portfolio projects
The 6 project cards are placeholders.  
Replace the titles, descriptions and (later) add real images or links to her actual work.

### 3. Colors
Accent colors are defined in the Tailwind config inside `index.html`:
- Coral: `#ff5252`
- Teal: `#14b8a6`

You can change them easily.

## How to host (free)

### Option A – Netlify (easiest)
1. Go to [netlify.com](https://www.netlify.com)
2. Drag & drop the entire folder
3. Get a free live URL instantly

### Option B – Vercel
1. Go to [vercel.com](https://vercel.com)
2. Import the folder or connect a GitHub repo
3. Deploy

### Option C – GitHub Pages
1. Create a new GitHub repository
2. Upload the files
3. Enable GitHub Pages in Settings → Pages
